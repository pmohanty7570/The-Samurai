Survivor Game

A 2D samurai survival platformer built in Python and Pygame for the Code Quest Hackathon 2025 (2nd place).

The Game

Survive three waves of attacking bats (3, 5, then 7) to become a true samurai. Bats wake up, hover, then chase you, so fight with your sword and watch your health.

Features: wave-based enemy AI, sword attacks, health bar with regeneration, animated sprites, and start, win, and lose screens.

Controls: A/D or arrows to move, W/Up to jump, Q to attack, R to play again.

Built with Python, Pygame, and GitHub Copilot (used for bat-following, code cleanup, music, and screen switching).
